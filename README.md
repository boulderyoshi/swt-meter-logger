# SWT Thickness Logger (Safari MVP)

iPhone SafariでSANKO SWT系の液晶表示をOCRし、CSVへ保存する専用ロガーです。

## v0.5

- 表示変化検出をv0.4より敏感化
  - 監視間隔: 約160ms
  - 標準感度の変化しきい値を引き下げ
  - 変化後2フレームの安定確認でOCR
- CSV操作をUI上で明示
  - `,` = 次の列
  - `\n` = 次の行
  - 「直前の操作」で、どちらへ進んだか表示
- 行ラベル付き測定表を追加
  - 左端ヘッダー
  - 測定ヘッダー
  - 行ラベル
- 行ラベル付き表では、必要回数を測り終えると自動で次の行へ進む
- 出力プレビューの現在セルを強調表示

## 行ラベル付き測定表

初期設定:

- 左端ヘッダー: `場所`
- 測定ヘッダー: `1回目,2回目,3回目`
- 行ラベル:

```text
A
B
C
```

作業順:

```text
場所 A / 1回目
  ↓ 測定
場所 A / 2回目      (,)
  ↓ 測定
場所 A / 3回目      (,)
  ↓ 測定
場所 B / 1回目      (\n)
```

CSV:

```csv
場所,1回目,2回目,3回目
A,123,345,678
B,321,543,876
```

## 「改行」の意味

UI上ではCSVの構造を次のように表現しています。

- `,` : 次のセル / 次の列
- `\n` : 現在行を終了して次の行

実際のCSVファイルではExcel互換性を優先し、行末をCRLFで出力します。
意味としては `\n` と同じ「次の行」です。

## 操作ボタン

- 「文字を現在セルへ」: 現在の入力先へ任意文字列を入れる
- 「, 次セル」: 現在セルを空欄のまま次の列へ進む
- 「\n 次行」: 残り列を空欄のまま次の行へ進む
- 測定値は保存後、自動的に次セルへ進む
- 行末の測定値を保存すると、自動的に `\n` 相当で次行へ進む

## OCR推奨設定

- 記録方法: 表示が変わったら記録
- 小数桁: 1桁固定
- 変化検出感度: 標準
- 白枠: 数字と小数点だけを含める

## 注意

CSVはExcelで表として開けますが、Excel固有の「テーブル」オブジェクトや罫線・色などの書式は保持しません。
必要になればXLSX直接出力を追加できます。

カメラ利用にはHTTPSが必要です。
Safariをバックグラウンドへ送ったり画面をロックすると、継続監視は保証されません。
