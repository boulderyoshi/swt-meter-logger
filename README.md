# SWT Thickness Logger (Safari MVP)

iPhone SafariでSANKO SWT系の液晶表示をOCRし、測定値をCSVへ保存・共有する専用ロガーです。

## v0.9

### QR管理番号モード

v0.9ではQR読取エンジンを大幅に変更しました。

- 単純なjsQR全画面720px解析を廃止し、qr-scannerのWorkerベースエンジンを主系統に変更
- 対応ブラウザではネイティブ BarcodeDetector を自動利用し、SafariではWorkerへフォールバック
- カメラ映像の新しいフレームに同期して解析し、同じフレームを無駄に再解析しない
- QRガイド周辺を高解像度で優先解析
- 通常は高速パス、一定回数失敗した時だけ高精細・広域パスを追加
- jsQRは常用せず、失敗時の補助フォールバックとしてのみ利用
- QRモードでは高解像度カメラ取得と連続AF/AEを可能な範囲で要求
- QRライブラリとWorkerを同一GitHub Pages配下へ配置し、通信・Worker起動の不安定要因を削減

これにより、読み取り精度を上げつつ、毎フレーム高負荷な全画面解析を行わない構成にしています。

### QR管理番号モード
設定の「読み取り対象」に次を追加しました。

- 数字OCR
- QR管理番号

QR管理番号モードでは、カメラをQRへ順番に向けるだけで連続登録します。

- QRを検出したら自動保存
- 一度登録した管理番号は重複登録しない
- 同じQRを再度向けた場合は「登録済み」と表示
- 成功時は対応端末で短い振動
- 最近5件を一覧表示
- 「1つ戻す」で直前の管理番号を削除し、そのQRを再登録可能にする
- QRモードでは数字OCR・小数設定・表形式設定を使わない

QRモードのCSVは固定形式です。

```csv
読取日時,管理番号
2026-09-29 10:40:12,A00120
2026-09-29 10:40:15,A00121
2026-09-29 10:40:19,A00122
```

CSVは「共有」「ファイル保存」の既存機能をそのまま利用できます。

## 数字OCRモード

### 通常画面
測定中に必要なものだけを表示します。

- 大きなカメラ映像
- OCR読取枠
- カメラ上の小型OCRプレビュー
- 現在値
- 現在の保存先
- カメラ接続
- 読み取りボタン
- 最近の記録 5件
- 1つ戻す
- 共有 / ファイル保存

設定類は画面上部の歯車ボタンからポップアップ表示します。

### 読み取りボタン
設定した読み取り方法によって同じボタンの役割が変わります。

- 手動読み取り: 「撮影」
- 自動読み取り: 「自動読み取り開始」
- 自動読み取り中: 「自動読み取り停止」

自動読み取りは次の2方式です。

- 画面の変化に連動
- 指定時間ごと

### OCR範囲調整
カメラ画像上の「範囲調整」から開きます。

- 横位置
- 縦位置
- 幅
- 高さ

カメラ画像を見たまま変更できます。

### 出力形式
数字OCRモードでは以下を選べます。

- シンプルCSV（改行なし1行）
- 表形式

表形式では列数と行数をそれぞれ独立して指定でき、列・行ヘッダーを「なし / 自動採番 / 任意入力」から選べます。

例:

```csv
場所,1回目,2回目,3回目
A,123,345,678
B,321,543,876
```

### 最近の記録
数字OCRモードでは最新5件を次の形式で表示します。

- 時間
- 列番号
- 行番号
- 値

CSV全体の表プレビューは別枠で、通常は折りたたんであります。

### 共有
「共有」はiOSの共有シートを利用します。

例:

- Mail
- Gmail
- AirDrop
- ファイル
- メッセージ
- CSVファイルを受け取れるその他のアプリ

「ファイル保存」はCSVを端末へ保存します。

Google Sheetsへの直接書き込みは未実装です。

## 注意

- カメラ利用にはHTTPSが必要です。
- Safariをバックグラウンドへ送ったり画面をロックすると継続監視は保証されません。
- QR読取にはjsQRをCDNから読み込むため、初回利用時はネット接続が必要です。
- CSVはExcelで表として開けますが、Excel固有のテーブル書式・罫線・色は保持しません。
