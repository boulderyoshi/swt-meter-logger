# SWT Thickness Logger (Safari MVP)

iPhone SafariでSANKO SWT系の液晶表示をOCRし、測定値をCSVへ保存・共有する専用ロガーです。

## v0.7

### 通常画面
測定中に必要なものだけを表示します。

- 大きなカメラ映像
- OCR読取枠
- カメラ上の小型OCRプレビュー
- 現在値
- 現在の保存先
- カメラ接続
- 読み取りボタン
- 最近の記録 5件
- 1つ戻す
- 共有 / ファイル保存

設定類は画面上部の歯車ボタンからポップアップ表示します。

### 読み取りボタン
設定した読み取り方法によって同じボタンの役割が変わります。

- 手動読み取り: 「撮影」
- 自動読み取り: 「自動読み取り開始」
- 自動読み取り中: 「自動読み取り停止」

自動読み取りは次の2方式です。

- 画面の変化に連動
- 指定時間ごと

### OCR範囲調整
カメラ画像上の「範囲調整」から開きます。

- 横位置
- 縦位置
- 幅
- 高さ

カメラ画像を見たまま変更できます。

### 出力形式の変更
測定値は内部では生データとして保持し、CSVの行列構造とは分離しました。

そのため、自動読み取りを停止した後で出力形式を変更しても、既に取得した測定値を捨てずに新しい表形式へ並べ替えられます。

### シンプルCSV
改行なしで1行へ保存します。

```csv
123.4,125.1,126.8,124.9
```

### 表形式
列数と行数をそれぞれ独立して指定できます。

- 列数あり + 行数あり: 左→右、指定列数ごとに次行。長方形を埋めたら完了
- 列数あり + 行数なし: 指定列数ごとに次行、行は自動追加
- 列数なし + 行数あり: 上→下、指定行数ごとに次列、列は自動追加
- 列数なし + 行数なし: 1行のまま右へ追加

列・行ヘッダーはそれぞれ以下から選べます。

- なし
- 自動採番
- 任意入力

例:

```csv
場所,1回目,2回目,3回目
A,123,345,678
B,321,543,876
```

### 最近の記録
通常画面には最新5件を縦表示します。

- 時間
- 列番号
- 行番号
- 値

CSV全体の表プレビューは別枠で、通常は折りたたんであります。

### 1つ戻す
直前に保存した測定値を削除します。
表形式では残った測定値から入力位置を再計算します。

### 共有
「共有」はiOSの共有シートを利用します。

例:

- Mail
- Gmail
- AirDrop
- ファイル
- メッセージ
- CSVファイルを受け取れるその他のアプリ

「ファイル保存」はCSVを端末へ保存します。

Google Sheetsへの直接書き込みは未実装です。
Google OAuthとSheets API設定が必要なため、共有・保存とは分離して後続実装します。

## OCR推奨設定

- 自動読み取り
- 画面の変化に連動
- 小数桁: 1桁固定
- 変化検出感度: 標準

変化監視は約120msごとに軽量な画像比較を行い、表示が変化したときだけOCRします。

## 注意

- カメラ利用にはHTTPSが必要です。
- Safariをバックグラウンドへ送ったり画面をロックすると継続監視は保証されません。
- CSVはExcelで表として開けますが、Excel固有のテーブル書式・罫線・色は保持しません。
