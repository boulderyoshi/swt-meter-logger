# SWT Logger

iPhone Safariで数字OCRまたはQRコードを読み取り、CSVへ保存・共有するWebロガーです。

## v0.12

### 上部メニュー
画面上部に4つの設定ボタンを配置しています。

- 読取対象
- 読取範囲
- 読取方式
- 出力方法

同時に表示されるメニューは1つだけで、内容はカメラ画像の直下に表示されます。
各メニューに「設定保存」「閉じる」があります。
設定はlocalStorageへ保存され、テストモードでも利用します。

### 読取対象
デフォルトは「数字」です。

数字:
- 整数（デフォルト）
- 小数点
  - 桁数 1～5
  - デフォルト 1

QRコード:
- QR連続読取
- 重複管理番号は二重保存しない
- 難読QRは最良フレーム選択、局所コントラスト補正、ZXing-C++ WASMの順で救済
- 登録成功時は緑フラッシュと短い成功音

数字OCRとQRコードは同じ出力エンジンを使うため、どちらも1行出力・表形式出力を選べます。

### 読取範囲
数字OCRとQRコードで別々の読取範囲を保存します。

- 横位置
- 縦位置
- 枠の横幅
- 枠の縦幅

読取対象を切り替えると、それぞれ保存済みの範囲へ切り替わります。

### 読取方式
デフォルトは「自動」です。

- 手動
- 自動
  - 画面変化式（デフォルト）
  - タイマー式
    - 1～300秒
    - デフォルト 5秒

手動では「撮影」、自動では「読み取り開始 / 停止」として同じ操作ボタンを使います。

### 出力方法

#### 1行
デフォルトです。

```csv
123,456,789
```

QRでも同じ形式で出力できます。

```csv
Q980184M,Q980238M,Q980412M
```

#### 表形式
必要な設定だけチェックします。

- 横（列数）
  - 1以上
  - 初期値 1
- 縦（行）
  - 1以上
  - 初期値 1
  - 指定した行数を超えると読み取り停止
- 空白・任意改行を許可
  - 有効時のみ操作盤に「空白」「改行（次の行）」を表示

表形式の行・列ヘッダーは自動採番です。

例:

```csv
,1,2,3
1,123,345,678
2,321,543,876
```

### テストモード
操作盤の「テストモード」を押すと、保存済み設定を読み込んでテストできます。

- 読み取りは通常どおり実行
- データ保存はしない
- カメラ画面に「テストモード」表示
- 紫色の視覚効果を追加
- 終了時はテスト開始前の未保存設定へ戻る

### 操作順
通常画面では、

1. カメラ接続
2. 読み取り開始

の順番が分かるよう表示しています。

### 最近の記録
最新5件を縦表示します。

- 時間
- 列番号
- 行番号
- 値

表全体のプレビューは別枠で、通常は折りたたんであります。

### 出力
- iOS共有シート
- CSVファイル保存

Google Sheets直接出力は未実装です。

## 注意
- カメラ利用にはHTTPSが必要です。
- Safariをバックグラウンドへ送ったり画面をロックすると継続監視は保証されません。
- QR補助デコーダの一部はCDN/WASMを利用します。
