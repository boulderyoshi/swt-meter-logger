# SWT Thickness Logger (Safari MVP)

iPhone SafariでSANKO SWT系の液晶表示をOCRし、測定値をCSVへ保存・共有する専用ロガーです。

## v0.6

### 通常画面を簡素化
普段の測定画面には次だけを常時表示します。

- カメラ
- カメラ上の小型OCRプレビュー
- 現在値
- 現在の保存先
- 1回読む
- 監視開始 / 停止
- 1つ戻す
- 共有
- ファイル保存

OCRのしきい値・感度・小数桁・読取枠などは「高度な設定」に移動しました。

### 出力形式

#### 1. シンプルCSV
初期値です。

測定値を改行せず1行へ追加します。

```csv
123.4,125.1,126.8,124.9
```

#### 2. 表形式
列数と行数を、それぞれ独立して「指定する / 指定しない」にできます。

- 列数あり + 行数あり
  - 左→右、行末で次行
  - 指定した長方形を埋めたら完了
- 列数あり + 行数なし
  - 指定列数ごとに改行
  - 行は自動追加
- 列数なし + 行数あり
  - 上→下に埋め、指定行数ごとに次列
  - 列は自動追加
- 列数なし + 行数なし
  - 1行のまま右方向へ追加

### ヘッダー
列・行それぞれで選択できます。

- なし
- 自動採番
- 任意入力

任意入力はカンマまたは改行区切りです。

例:

- 列ヘッダー: `1回目,2回目,3回目`
- 行ヘッダー:
  ```text
  A
  B
  C
  ```
- 左上見出し: `場所`

出力:

```csv
場所,1回目,2回目,3回目
A,123,345,678
B,321,543,876
C,111,222,333
```

### 1つ戻す
直前に保存した測定値を削除し、表形式では入力位置もそのセルへ戻します。

### 共有
「共有」はiOSの共有シートを使います。
利用可能な共有先はiPhone側の環境に依存します。

例:

- Mail
- Gmail
- AirDrop
- ファイル
- メッセージ
- その他、CSVファイルを受け取れるアプリ

「ファイル保存」は従来どおりCSVを端末へ保存します。

Google Sheetsへの直接書き込みは未実装です。
直接連携にはGoogle OAuthとSheets API設定が必要なため、共有・保存とは分離して後続実装とします。

## OCR
推奨初期値:

- 記録方法: 表示が変わったら記録
- 小数桁: 1桁固定
- 変化検出感度: 標準

v0.6では変化検出をさらに敏感化し、約120ms間隔で軽量な画像比較を行います。
変化後の画像が安定した時だけOCRを実行します。

## 注意
- カメラ利用にはHTTPSが必要です。
- Safariをバックグラウンドへ送ったり画面をロックすると継続監視は保証されません。
- CSVはExcelで表として開けますが、Excel固有の「テーブル」オブジェクト、罫線、色などは保持しません。
