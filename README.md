# SWT Thickness Logger (Safari MVP)

iPhone SafariでSANKO SWT系の液晶表示をOCRし、CSVへ保存する専用ロガーです。

## 現在の機能
- iPhone背面カメラ
- 読み取り枠の幅・高さ・縦位置調整
- Tesseract.js + 前処理による端末内OCR
- 小数桁を 0 / 1 / 2桁固定、または自動に設定
- 「表示が変わったら記録」モード
- 1 / 5 / 10 / 30 / 60秒の一定間隔記録モード
- OCR失敗を `OCR_ERROR` として記録
- CSV内へ任意文字列を1行挿入
- CSV内へ空行を挿入
- CSV保存

## 推奨設定
このSWT液晶では、まず以下を推奨します。

- 記録方法: 表示が変わったら記録
- 小数桁: 1桁固定
- 変化検出感度: 標準
- 白枠: 数字と小数点だけが入るように合わせる

「1桁固定」では、OCRが `1182` と読んでも `118.2` として保存します。
これにより、小数点そのものの認識成否に左右されにくくしています。

## 表示変化の検出
表示変化モードではOCRを常時回しません。

1. 読取枠の縮小画像を約250msごとに比較
2. 表示が変わったと判断
3. 変化後の画像が数フレーム安定したことを確認
4. OCRを1回実行
5. CSVへ保存

これにより、同じ値を延々と記録せず、液晶が変化した時だけOCRします。

## CSV追記
測定中でも「CSVへ追記」から次を任意位置に追加できます。

- 任意文字列（例: 試料A、測定前、再測定）
- 空行

出力例:

```csv
timestamp,value,unit,status
2026-09-28 13:30:01,118.2,µm,OK
試料A

2026-09-28 13:31:14,121.7,µm,OK
```

## 重要
カメラ (`getUserMedia`) は原則として HTTPS が必要です。
GitHub Pages の HTTPS URLをiPhone Safariで開いて使用してください。

Safariをバックグラウンドへ送ったり画面をロックすると、継続監視は保証されません。
