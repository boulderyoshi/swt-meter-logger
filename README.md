# SWT Thickness Logger (Safari MVP)

iPhone SafariでSANKO SWT系の液晶表示をOCRし、CSVへ保存する専用ロガーです。

## v0.4
- 作業画面を1画面中心に再設計
- 読み取り設定は折りたたみ式
- カメラ開始後は設定を自動で閉じる
- 出力形式を最初に選択
  - ログ表: timestamp / value / unit / status / note
  - 自由表: 任意の列名を指定し、横方向に値や文字列を入力
- 「改行（次の行）」を実装
- 任意文字列はセル内改行にも対応
- CSVはUTF-8 BOM付きでExcelで開きやすい形式
- 表示変化時だけOCRするモードを継続

## Excel向け出力

### ログ表
```csv
timestamp,value,unit,status,note
2026-09-28 13:30:01,118.2,µm,OK,
2026-09-28 13:30:20,,,,試料A
2026-09-28 13:30:31,121.7,µm,OK,
```

### 自由表
初期設定で列名を `左,中央,右` とした場合:

```csv
左,中央,右
118.2,119.0,117.6
120.1,121.4,119.8
```

値または任意文字列を現在セルへ入れると、次の列へ自動で進みます。
「改行（次の行）」で残りセルを空欄のまま次の行へ移動します。

## セル内改行
文字入力欄は複数行に対応しています。
CSVでは改行を含む文字列をダブルクォートで囲んで保存するため、Excelでは1セル内の改行として扱えます。

## 推奨設定
- 記録方法: 表示が変わったら記録
- 小数桁: 1桁固定
- 変化検出感度: 標準
- 白枠: 数字と小数点だけを含める

## 注意
CSVは行・列データを持てますが、Excel固有の「テーブル」オブジェクトや書式は保持できません。
Excelの正式なテーブル機能や書式まで自動生成したい場合は、CSVではなくXLSX出力を追加する必要があります。

カメラ利用にはHTTPSが必要です。
Safariをバックグラウンドへ送ったり画面をロックすると、継続監視は保証されません。
